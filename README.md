# The Blackwater Signal

A complete, mobile-friendly original survival-horror mini-campaign. Guide field agent Mara Venn through three chapters, survive the infected, and reach each signal point to uncover the story.

## Play

Open `index.html` in a browser (or serve this folder with any static web server). On desktop, use **WASD / arrow keys** to move, **mouse** to aim and shoot, **R** to reload, and **E** to use a medkit. On phones, use the **left thumbstick** to move and hold **FIRE** to shoot; the game automatically aims at nearby threats. Use **✚** for a medkit and **↻** to reload.

The game is designed for both phone and desktop screens, with responsive canvas rendering, rain, atmospheric lighting, and touch controls. It is an original short story—not a reproduction of another game's story, characters, or assets.
